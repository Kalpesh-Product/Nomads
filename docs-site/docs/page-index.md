These are paths on the Nomad website. A segment in angle brackets stands for a value such as a listing name or an item ID.

| Feature | Nomad website paths | User guide |
| --- | --- | --- |
| Home | `/`, `/home-logged-in` | [Choose a goal](./getting-started/choose-a-goal.md) |
| Ranking and discovery | `/world-rankings`, `/search`, `/savings`, `/career-search`, `/compatible` | [Destination discovery](./discovery/overview.md) |
| Ranked results | `/search/results`, `/search/<goal>/results`, `/savings/results`, `/career-search/results`, `/compatible/results` | [Search results](./discovery/search-results.md) |
| Classic Search | `/manual-search` | [Classic Search](./discovery/classic-search.md) |
| Destination hub and listings | `/verticals`, `/listings`, `/listings-list` | [Destination hub](./destinations/destination-hub.md) |
| Listing and photos | `/listings/<company>`, `/listings/<company>/images` | [Listing details](./destinations/listing-details.md) |
| Restaurants and photos | `/restaurants/<id>`, `/restaurants/<id>/images` | [Cafes and restaurants](./destinations/cafes-and-restaurants.md) |
| Places and events | `/places/<id>`, `/events/<id>` | [Places](./destinations/places.md), [Events](./destinations/events.md) |
| Articles | `/blog`, `/blog/blog-details`, `/news`, `/news/news-details` | [Blogs](./destinations/blogs.md), [News](./destinations/news.md) |
| Support requests | `/visa-support`, `/visa-support/thank-you`, `/overall-activation-support`, `/new-company-setup`, `/consultation`, `/workation` | [Value-added services](./services/overview.md) |
| Account access | `/signup`, `/login`, `/login/<redirectGoal>` | [Sign up](./account/sign-up.md), [Log in](./account/log-in.md) |
| Password recovery | `/forgot-password`, `/forgot-password/verify`, `/forgot-password/reset`, `/reset-password/<token>` | [Reset your password](./account/reset-your-password.md) |
| Profile, password, favorites and reviews | `/profile` with `?tab=profile`, `?tab=password`, `?tab=favorites` or `?tab=reviews` | [Manage your profile](./account/manage-your-profile.md) |
| Contributor application and dashboard | `/become-a-contributor`, `/contributions` | [Contributor program](./contributing/become-a-contributor.md) |
| Contribution lists | `/contributions/all`, `/contributions/<type>` | [Manage contributions](./contributing/manage-contributions.md) |
| Create and preview a contribution | `/contributions/<type>/add`, `/contributions/<type>/<id>` | [Create a contribution](./contributing/create-a-contribution.md), [Preview and edit](./contributing/preview-and-edit.md) |
| Information and careers | `/about`, `/contact`, `/career`, `/career/job/<title>`, `/faq` | [Contact](./help/contact.md), [Careers](./help/careers.md), [FAQ](./help/faq.md) |
| Policies | `/terms-and-conditions`, `/privacy`, `/content-and-copyright`, `/content-use-removal` | [Legal pages](./help/legal-pages.md) |
| Outages and maintenance | `/site-is-down`, `/website-under-maintenance` | [Status pages](./help/status-pages.md) |

For contribution paths, use `blog`, `news`, `event` or `places` in place of `<type>`. If an older bookmark takes you to a previous version of WONO, use the current site's menus to find the same feature.
