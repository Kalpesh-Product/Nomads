Route: /visa-support. For visitors who want help with a visa.

- Visa Type options: Explore / Travel, Work Remotely, Get a Job Abroad, Study Abroad, Start or Expand a Business, Relocate / Settle Long-Term, Move with Family, Not Sure - Need Recommendation.
- Fields: Full Name, Nationality on Passport, Travelling Country, Travelling City / State, Contact Number with country code, Email Address, Additional Comments.
- After submit: A Visa Support Request Submitted dialog, then a thank-you page at /visa-support/thank-you. The page confirms the request and then forwards the visitor to their chosen country’s destination.
