Open **Modules** to see the tools that come with the Host product. The page is a tour of the platform: a summary at the top, then one block per area of the business.

[Open the Modules page](http://host.localhost:5173/modules)

![Host Modules page with the platform summary and real-time operations dashboard](/img/guide/host-modules.webp)

## What the page shows

- A headline describing the platform as the Nomad ecosystem SaaS, with the tools listed underneath: No Code Website, Booking Engine, Payment Gateway, Accounting, Reports, Analytics, HR Support, Customer & Client Management, Marketing and more.
- **Get Started** in the top right, which opens the host sign-up form.
- **Real-time operations**, a live dashboard showing income and expense over time with the income, expense and net savings totals beneath it.

## Module groups

Each group below is a row on the page, with the features on one side and a screenshot of the module on the other.

- **Frontend** — No Code Website, Booking Engine, Payment Gateway, Lead Management, AI SEO, Notifications.
- **Apps** — Tickets, Tasks, Meeting Rooms, Visitors, Assets, Calendar.
- **Sales** — Revenue Reports, Lead Generation, Sales Inventory, Occupancy, Manage Clients, Profiling.
- **Finance** — P&L Report, Cashflow, Invoicing, Collections, Historical Data, Budgeting.

More modules are marked as coming soon. [Get Started](http://host.localhost:5173/signup?step=1) appears again at the end of the page.
