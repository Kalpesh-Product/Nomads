---
title: "Create a contribution"
sidebar_position: 6
---

In **Contributions**, choose **Add** for a type approved for your account. Select the continent, country and location, then fill in the fields for that type. Choose **Save as Draft** to keep working later. When the entry is ready, choose **Publish** to send it for review. Its status is **Pending** until WONO reviews it. If you choose **Cancel**, confirm before discarding your changes.

| Type | Page | Fields (besides Continent, Country, Location) | Buttons |
| --- | --- | --- | --- |
| Blog | /contributions/blog/add | Main Title, Main Image (upload or URL), Source (optional), Main Content, Sections (each with Section Title, optional Section Image URL and Section Content; more can be added) | Save as Draft, Publish Blog, Cancel |
| News | /contributions/news/add | Same as Blog | Save as Draft, Publish News, Cancel |
| Event | /contributions/event/add | Event Name, Main Image, Category, Venue, Type, Short Description | Save as Draft, Publish Event, Cancel |
| Place | /contributions/places/add | Place Name, Main Image, Address, Google Maps Link, Category, Venue (optional), Latitude, Longitude, Short Description | Save as Draft, Publish Place, Cancel |
