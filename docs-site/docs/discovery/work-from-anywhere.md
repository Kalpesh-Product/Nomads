title: "Work From Anywhere"
sidebar_position: 3
---

Choose Work From Anywhere from the home page or sidebar. Select a region and a ranking goal, such as Best for Remote Work Setup, to compare destinations. Open a destination card to see places to work, stay and explore.

In results, the Work From Anywhere goal adds these lenses: Best for Remote Work Setup, Cheapest Places, Best Connected Cities (Flights), Strong Nomad Community, Fast Internet Cities and Best Work Infrastructure.
